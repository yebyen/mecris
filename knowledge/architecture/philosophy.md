# The Diseased Forest

The project metaphor names local durable data the **Ancient Forest**, cloud machines the **Iron Heart**, and JSON/WIT the **Standard of Bone**. The metaphor is useful for navigating design intent, but operational claims belong in the deployment and data concepts.

The current strategic posture is reversible cloud easing: local Python MCP is primary for interactive sessions; Akamai is the active authoritative edge; Fermyon is inactive. This concept records intent and language, not a substitute for current health checks.
