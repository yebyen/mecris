# Architecture
* [Mecris System Architecture Overview](overview.md) - Mecris is a personal accountability system with Python MCP server, Go services, Android client, and Spin cloud deployment. Core loop: Orient → Plan → Archive → PR-Test.
* [MCP Server (mcp_server.py)](mcp-server.md) - Main Python MCP server exposing 50+ tools for Beeminder goals, budget tracking, language learning, scheduling, GitHub integration, and system health monitoring. Runs as stdio MCP server for Claude Code.
* [Go Services (mecris-go, mecris-go-spin, mecris-go-project)](go-services.md) - Go-based services for performance-critical paths: mecris-go (core), mecris-go-spin (Spin/WASM cloud deployment), mecris-go-project (project tooling). Communicate via gRPC/HTTP with Python MCP server.
* [Beeminder Goal Integration](beeminder-integration.md) - Integration with Beeminder API for goal tracking, daily activity aggregation, alerts, and progress visualization via Majesty Cake widget. Uses webhook endpoints and polling for status updates.
* [Urbit Gall Agent Pattern Loop](gall-loop.md) - Core development loop modeled on Urbit Gall: /mecris-orient (situation report), /mecris-plan (spec issue), [work], /mecris-archive (serialize state), /mecris-pr-test (dispatch test pipeline). Maps to on-peek, on-poke, on-save, on-agent arms.
* [Specialized Technical Skills Integration](specialized-skills.md) - Integrated skills from kingdon-skills repository: /author-skills, /follow-leader, /sdd, /atomic, /tdg, /ticket-author, /postmortem-author, /start-blasting, /hallucination-detector, /sos-emergency, plus infra/observability skills like /prometheus-status, /alertmanager-install, etc.
* [Mecris Architectural Philosophy: The Diseased Forest](philosophy.md) - From ARCHITECTURE.md: Mecris as a parasite that feeds on human failure, built on Iron Town (cloud) and Ancient Forest (local data). Features Neon DB as forest floor, Iron Heart as cloud machines, Standard of Bone as JSON/WIT language. pivoted to Local Python MCP after cloud outages in June 2026.
